# Ultra-HATS-Hybrid

Custom Nintendo Switch Homebrew Pack combining:
- **Performance Base**: UltraNX (Atmosphère 1.12.1 + Horizon OC 2.6.0 + Ultra-Tuner + SaltyNX 2.1.3 + FPSLocker + MissionControl + sys-con).
- **Utilities & Tools**: HATS (Anti-Ban hosts, JKSV, Linkalho, NXThemesInstaller, NX-Activity-Log, QuickNTP, emuiibo, ldn_mitm, rescue payloads).

---

## 🎮 Accesos directos y atajos
- **Homebrew Menu (Hbmenu)**: Abrir el Álbum de fotos (o mantener presionado `R` al iniciar cualquier juego para modo Full RAM).
- **Menú de Overlays (Ultrahand)**: `L + R + Flecha Arriba` (o `L + Flecha Abajo + R3`).
- **Menú Hekate**: Mantener presionado `Volumen Menos (-)` durante el encendido.

---

## ⚡ Configuración de Overclock / Undervolt recomendada
- **Consola V1 (Erista)**:
  - Undervolt: Perfil `Red` (o `Core`/`Mega`).
  - RAM Overclock: Perfil `Core` (1996 MHz).
- **Consola V2 / OLED (Mariko)**:
  - Undervolt: Perfil `Core` o `Mega`.
  - RAM Overclock: Perfil `Balance` (1862/1996 MHz).
